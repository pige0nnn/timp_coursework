## Описание проекта

Серверное приложение для клиент-серверной системы обработки данных. Программа реализует протокол взаимодействия с клиентом по TCP, включающий аутентификацию по хеш-функции SHA-224 и обработку числовых векторов.

**Основные возможности:**
*   Загрузка базы клиентов из файла при старте.
*   Аутентификация клиента (логин, соль, хеш SHA-224).
*   Приём числовых векторов (тип `double`) в двоичном формате.
*   Вычисление произведения элементов вектора.
*   Отправка результатов обратно клиенту.
*   Ведение журнала ошибок с указанием даты, времени и критичности.
*   Гибкий интерфейс командной строки с поддержкой справки.

## Зависимости

Для сборки и работы программы требуются следующие библиотеки:
*   **C++17** (компилятор g++)
*   **CMake** (система сборки)
*   **Boost** (компонент `program_options` для парсинга аргументов командной строки)
*   **Crypto++** (для хеш-функции SHA-224)
*   **pkg-config** (для поиска библиотеки Crypto++ в CMake)

## Модульное тестирование

В проекте реализованы модульные тесты с использованием фреймворка **UnitTest++**. 
Тесты покрывают основные модули:
*   `ClientDB` (загрузка базы и поиск пользователей)
*   `Authenticator` (хеширование SHA-224)
*   `VectorProcessor` (вычисление произведения векторов)
*   `UserInterface` (парсинг аргументов командной строки)
*   `Logger` (запись в журнал)

### Установка UnitTest++
Для сборки тестов необходимо установить библиотеку:
```bash
sudo apt install libunittest++-dev
```

### Установка зависимостей (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install build-essential cmake pkg-config libboost-program-options-dev libcrypto++-dev
```

Скопируйте и выполните следующие команды в терминале:

```bash
